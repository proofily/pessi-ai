# PessiAI

Comic Sans AI chat with a public human page and a private owner console.

## Run locally
1. Copy `.env.example` to `.env`.
2. Change `OWNER_PASSWORD` and `SESSION_SECRET` in `.env`.
3. Run `npm install`, then `npm start`.
4. Human page: http://localhost:3000
5. Owner login: http://localhost:3000/owner-login

The AI profile image is `public/profile.png`. Replace it with your own picture using the same filename.
